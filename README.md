# 房车比价通（RV-Compare）

二手房车信息聚合与比价工具。自动爬取多个主流二手房车网站的挂牌车源（3000+ 台），
整合入库后提供：车源列表浏览、多维度筛选、**跨源同款**（同底盘型号）比价、
同年限行情对比、**价格历史与降价监测**、收藏、多车横向对比、JSON API 与 CSV 导出。

线上版（GitHub Pages 静态站，手机/电脑可访问）：`docs/` 目录随每次刷新自动导出部署。

## 数据源

| 来源 | 标识 | 说明 |
|---|---|---|
| 房车猫（rv28.com） | `rv28` | 二手房车论坛专区，HTML 列表+详情页。**每天都有新车源**，是目前的主力活跃源 |
| 21世纪房车（wanfangche API） | `21rv` | 经其二手板块 JSON API（3224 台在售），底盘型号从标题/配置自动规范化，与房车猫同款可聚到同一比价组。**⚠ 上游自 2026-04-23 起停止发布新车源**（详见下方"数据源健康"）。**⚠ 2026-09 源端接口劣化：`size` 大于 ~20 时响应挂起/超时，爬虫已把默认分页降到 20** |
| 舒旅二手房车网（cn2rv.com） | `cn2rv` | 专注二手房车的直卖平台（约 254 台在售），列表页+详情页均为静态 HTML，上牌时间/公里数/所在地/排放/价格以成对标签呈现，可直接解析。**⚠ 2026-09 站点改版，旧列表入口 `/buycar/list`、`/buycar/list-ob{1..160}` 已失效，爬虫已改用分页入口 `/buycar/?page=N`（24 条/页）** |

`vehicles.source` 字段区分来源；列表页可按来源筛选，卡片/详情/比价页标注来源。

## 数据源健康（重要）

页面顶部会显示各源的"最后一条挂牌时间"，并在某源长期没有新车源时给出提示。
**这不是抓取故障**——爬虫每次都会正常访问源站接口/页面并把结果记进 `crawl_runs` 表。

```
python crawl_21rv.py --status      # 体检 21世纪房车：接口是否正常、源站最新挂牌是哪天
```

截至 2026-09-18 的体检结论：

| 源 | 车源数 | 停更判断依据 | 状态 |
|---|---|---|---|
| 21rv | 3224 | 源站最新挂牌 2026-04-23 | ⚠ 上游停更 148 天（接口本身正常） |
| rv28 | 394 | 源站最新挂牌 2026-09-16 | 正常（每日有新帖） |
| cn2rv | 236 | 源站不提供发布时间，按本站收录推断 | 正常 |

判断口径分两种（`window.RV_SOURCES` 里的 `basis` 字段标明）：

- **`basis=source`**：源站自己给出了发布时间，判断精确。
  - `21rv`：列表接口的 `created_at`；
  - `rv28`：帖子页 `em#authorposton` 的发布时间（Discuz 会把近几天渲染成
    "前天 21:58"，真实时间只在 `title` 属性里，代码已优先读 `title`）。
  - 超过 `RV_STALE_DAYS`（默认 14 天）没有新挂牌 → 打"停更"标记。
- **`basis=local`**：源站不给发布时间（如 `cn2rv` 列表/详情页均无日期字段），
  退而用"本站最近收录到新车源的时间"（`vehicles.first_seen`）保守推断。
  阈值更宽（`RV_LOCAL_STALE_DAYS`，默认 45 天），措辞也软——只能说
  "本站多久没收到新车源"，不断言上游停更。小众源几周没新车是正常的，
  收紧阈值只会误报，那比漏报更伤信任。

- Windows 10/11，Python 3.10+

  pip install requests beautifulsoup4 flask

## 快速开始

```
# 1. 抓取房车猫（前10页列表+详情，约160条，礼貌限速）
python crawl.py --pages 10

# 2. 抓取21世纪房车（全量盘点 3224 台，约33次请求）
python crawl_21rv.py --full

# 3. 抓取舒旅二手房车网（全量约230台）
python crawl_cn2rv.py

# 4. 启动比价应用
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

## 功能

| 页面 | 说明 |
|---|---|
| 车源列表 | 关键词/类型/底盘品牌/年份/价格区间/来源筛选，排序分页（含"最新挂牌"）；卡片含图片、降价标签、收藏（🤍，本地保存）、多选对比勾选 |
| 车源详情 | 大图 + 完整车况：上牌时间、里程、排放、过户、底盘、源站挂牌时间；同款快速比价入口；手机底部大按钮（看原文 / 返回） |
| 多车对比 | 勾选 2~3 台逐项并排对比；桌面端表格、手机端每台一张卡 |
| 降价榜 | 对比每台车最近两次抓取的挂牌价，降幅排序；列表卡片同步显示"较首录降价" |
| 同款比价 | 按底盘型号聚合（如依维柯欧盛、大通V90），展示最低/均价/中位/最高，可再按上装品牌、年份筛选 |
| 行情总览 | 价格区间分布、类型/底盘品牌分布、各数据源统计、各年份上牌均价、品牌TOP20、降价车源数 |
| 数据源健康 | 页头提示长期无更新的源，并说明"不是抓取故障"；按判断依据分别措辞（源站发布时间 / 本站收录时间），可关闭（按天记忆） |
| 手机适配 | 安全区（刘海屏/全面屏）适配；列表 2 列（超窄屏 1 列）卡片；筛选面板可折叠并回显生效条件；宽表在手机上自动转卡片；图片懒加载 + 4:3 占位防抖动；回到顶部；输入框 16px 防 iOS 自动放大 |
| 深色模式 | 本地 Flask 版顶栏 🌙 切换，偏好本地记忆 |

JSON API（与页面同源，可直接调用）：

```
GET /api/vehicles?kw=V90&pmin=10&pmax=30&page=1&per_page=24
GET /api/vehicle/<tid>          # 含 specs 与 price_history
GET /api/stats                  # 行情总览统计
GET /api/drops                  # 降价榜
GET /export.csv?kw=&pmin=...    # 按筛选条件导出 CSV（Excel 友好）
```

## 爬虫命令

```
# 房车猫（HTML，礼貌限速，请勿调高频率）
python crawl.py --pages 10          # 抓前10页列表+详情（推荐）
python crawl.py --pages 30          # 抓前30页
python crawl.py --pages 5 --no-details   # 只抓列表摘要（快）
python crawl.py --details-only      # 为已入库但缺详情的记录补抓详情

# 21世纪房车（JSON API，默认 size=20；上游接口劣化，size 大于约 20 会挂起超时）
python crawl_21rv.py --status        # 只体检数据源（接口是否正常 / 源站最新挂牌是哪天）
python crawl_21rv.py --full          # 全量盘点：约161次请求翻完源站全部在售车源（推荐）
python crawl_21rv.py --full --no-details   # 只同步列表摘要（最快，用于回填挂牌时间）
python crawl_21rv.py --pages 2       # 只刷最新2页=40台（求快时用）
python crawl_21rv.py --details-only          # 为缺详情的记录补抓
python crawl_21rv.py --details-only --force  # 强制重新抓取已有详情（改版后使用）

# 舒旅二手房车网（静态 HTML 分页列表，全量约254台）
python crawl_cn2rv.py               # 列表+全部详情
python crawl_cn2rv.py --no-details  # 只抓列表摘要
python crawl_cn2rv.py --details-only   # 补抓缺详情的记录
python crawl_cn2rv.py --force          # 强制重抓已有详情
```

- 反爬策略：房车猫首次请求返回403并种cookie，爬虫自动携带cookie立即重试同一地址放行；21世纪房车走公开 API。
- 限速：房车猫每页/每详情随机等待1.2~2.2秒，21世纪房车 0.4~1.0 秒，请勿调高频率。
- 去重：`tid` 为主键，跨源以 `21rv_`/`rv28_` 前缀命名空间化避免撞号，重复运行只增量更新；
  已入库车源在列表刷新时会同步更新挂牌价，价格变化写入 `price_history` 表（降价榜数据来源）。
- 数据文件：`data/rv.db`（SQLite，可直接用工具查看）。

## 已修复的坑（2026-09-18）

1. **"除了房车猫，其他两个站都读不出来"** —— 两个源是**两个不同的故障**，分别修：

   - **cn2rv 全站抓不到（0 条）**：源站 **2026-09 改版**。旧列表入口
     `/buycar/list` 现在返回首页壳（12 个推荐位），160 个品牌分类页
     `/buycar/list-ob{1..160}` 渲染成空列表——所以 `crawl_list` 只能捞到十几条、
     且详情几乎全是旧的。新列表改成**分页式** `/buycar/?page=N`（24 条/页，
     约 11 页 254 台，`?page=` 越界返回空页）。已重写 `crawl_list` 按页翻到空页为止，
     并加 `LIST_MAX_PAGES=40` 兜底；`_link_items` 改为优先取卡片里的
     `h4.car-title`，否则会把描述/价格一起塞进标题。详情页解析（`_pairs` /
     `_parse_price` 的 `jx_timeNum` 成对标签）经实测**仍然有效**，未改。
     修复后实跑：列表 254 条全捞回、新增 24 条、详情 22 更新 / 0 失败。

   - **21rv 时好时坏、整轮报"接口不可用"**：根因不是网络也不是代码逻辑，是
     **上游接口性能劣化**——实测同一列表接口，`size=5` 稳定 0.7~2.6s，
     `size=20` 2~5s，而 `size>=30` 频繁挂起 30~95s 后 `ReadTimeout`／
     `ConnectionError`（爬虫旧的默认 `size=100` 正好落在劣化区间，所以每页必挂，
     3 次重试全超时 → 判为"接口不可用"）。单 IP、无 DNS 轮询问题，与请求头无关
     （对照测过带/不带 `Origin` 都能通）。修复：默认 `PAGE_SIZE` 从 100 降到 **20**
     （代价是全量盘点从约 33 次请求变成约 161 次，慢一些但跑得完），
     同时把 `get_json` 重试从 3 次提到 **5 次并做指数退避**（1/2/4/8s 封顶 10s）。
     修复后 `--pages 3` 实跑 60 条全通（中途 1 次 ConnectionError 被退避重试救回）。
     注意该源仍是**上游停更**（最新挂牌停在 2026-04-23），抓取链路修好后也不会有新车源。

2. **21rv 价格单位混用（元 / 万元）** —— 接口不带单位字段，约 16 条按"元"入库
   （如 `218000`），与其余"万元"口径（如 `11.0`）混在一起。后果：21rv 源均价被拉到
   **380.85 万**（真实 23 万左右），比价页同型号最低/均价/中位、价格排序、价格筛选、
   降价榜全部失真。实测两套口径有清晰断层（万元口径最大 300，元口径最小 20000）。
   修复分两层：
   - `crawl_21rv.clean_price()`：数值 >1000 时先按"元"换算，换算结果 ≥0.5 万才采纳
     （防误伤真有的千万级房车）；0/负数视为无效价返回 None（前端显示"面议"）。
     `cn2rv._parse_price` 原本就有 >500 换算逻辑，口径一致。
   - `database._migrate` 新增幂等一次性清洗 `_fix_price_units()`：
     `price/new_price/price_history.price >1000` 一律 ÷10000，`<=0` 置 NULL/删除。
     修完再跑不命中，重复运行安全。

3. **网页健壮性（静态站 + Flask 模板）** —— 静态站 `docs/index.html`：
   - `esc()` 漏转单引号，且 `openDetail('tid')` / `openCmpGroup('型号')` 等把数据直接
     拼进单引号 onclick——标题一旦含 `'` 就会截断属性甚至注入脚本。已补单引号转义，
     并新增 `jsAttr()`（JSON.stringify + 实体化双引号 + `<` 转 `\u003c`）统一所有
     事件属性拼接处。
   - 空价格导致 `Math.min.apply(null, [])` → `Infinity`、`toFixed` 报错：
     `renderSame`/`renderCmpDetail` 在分组无有效价格时改显示提示文案；并排对比价格行改用带兜底的 `fmtP`。
   - Flask 模板：`fmt_mileage` 改为自带单位（原先生成"面议 万""-公里"）；
     价格 NULL 时列表/详情/对比页显示"面议"且不再拼"万"；
     `side.html` 的 `prices|min` 会把 None 混进比较（Python3 TypeError → 页面 500），
     已先 `select` 过滤空价再求 min/max。
   - 验证：Node 抽取内联脚本跑语法 + 假 DOM 冒烟（空价、含引号/尖括号标题的边界样本，
     见 `probe/_smoke_static.js`）；Flask 侧 `probe/_smoke_pages.py` 渲染全部页面 23 条 URL 全 200。
     编辑网页时注意：**脚本注释里不要写字面的 script 闭合标签**，会提前终结脚本块（本轮实际踩过）。

## 已修复的坑（2026-09-17）

1. **"21世纪房车抓不到数据"** —— 排查结论是**上游停更**，不是代码坏了：
   接口 `HTTP 200`、业务正常、返回 3224 台，但源站最新挂牌停在 `2026-04-23`。
   为了以后能一眼区分"抓不到"和"没得抓"，新增：
   - `crawl_21rv.py --status` 体检命令（打印接口状态 / 源站总量 / 最新挂牌 / 停更天数）
   - `crawl_runs` 表记录每次巡检；页面顶部据此显示"某源长期未更新"提示并说明不是抓取故障

2. **列表接口业务错误被当成"空页"吞掉** —— 源站对参数错误会返回 `HTTP 200 + {"msg":"请求失败","err":...}`；
   旧代码只在 HTTP 非 200 时重试，业务错误会被认作空页而**静默结束**（表现为"跑完了但一条没抓到"）。
   现在会识别 `err` / 缺 `data` 并重试、报错。

3. **"来源"筛选永远筛不出结果** —— 静态页 `fillSelect()` 把显示名（"房车猫"）当成了 option 的 value，
   而过滤逻辑比的是来源代码（`rv28`），于是选择任一来源都得到 0 台。
   已改为 value 用代码、显示用名称。

4. **`crawl.py --details-only` 没限定来源** —— 会把别的站的车源按房车猫的解析规则去抓，字段可能被写脏。
   已加 `WHERE source='rv28'`。

5. **21rv 列表只翻 2 页导致深处车源降价漏检** —— 列表接口支持 `size=100`，
   改为默认全量盘点（约 33 次请求），`refresh_deploy.py` 的每日刷新也换成 `--full`。

6. **`posted_at` / `first_seen`（停更判断的两个时间轴）** ——
   - `posted_at`：源站自己的发布时间。21rv 取自接口 `created_at`（精确）；
     rv28 取自帖子页 `em#authorposton`（`title` 属性优先，兼容 Discuz 的相对时间）。
   - `first_seen`：本站首次收录该车源的时间，只在插入时写入、后续永不被覆盖
     （`FROZEN_ON_INSERT`）。源站不提供发布时间时用它兜底。
   - 两者都随库自动迁移；老库 `first_seen` 用 `fetched_at` 近似回填——
     宁可记成"偏晚"（更保守、少报），也不谎称很早就见过（会误报）。
   - `export_data.py` 连同 `basis`（source / local）一起导出到 `window.RV_SOURCES`。

## 项目结构

```
rv-crawler/
├── crawl.py          # 房车猫爬虫（列表页+详情页解析入库）
├── crawl_21rv.py     # 21世纪房车爬虫（JSON API 列表+详情入库，含底盘型号规范化）
├── crawl_cn2rv.py    # 舒旅二手房车网爬虫（静态 HTML 列表+详情入库，复用底盘规范化）
├── database.py       # SQLite 存储与查询层（含价格历史）
├── export_data.py    # 导出 docs/data.js（GitHub Pages 静态站数据）
├── deploy/refresh_deploy.py  # 定时刷新：爬虫 -> 导出 -> git 提交推送
├── app.py            # Flask Web 应用（页面 + JSON API + CSV 导出）
├── templates/        # 页面模板
│   ├── base.html     # 公共布局（深色模式/收藏/对比栏/返回顶部）
│   ├── index.html    # 车源列表（筛选/收藏/多选对比/降价标签）
│   ├── detail.html   # 车源详情（配置清单/价格记录图）
│   ├── side.html     # 多车横向对比（2~4台并排）
│   ├── drops.html    # 降价榜
│   ├── compare.html  # 同款比价（跨源聚合，按来源标注）
│   └── stats.html    # 行情总览
├── docs/             # GitHub Pages 静态站（index.html + data.js）
└── data/rv.db        # 数据库（运行后生成）
```

## 后续扩展方向

1. **继续扩源**：房车猫、21世纪房车已接入；二手房车网（cn2rv.com）、58同城、瓜子/闲鱼等站点结构不同，
   按同样"列表+详情"模式新增解析器即可，`vehicles.source` 字段已预留来源标识。
2. **宿营车专区**：房车猫列表页已有"露营车"分类筛选项（leixing=9）；21世纪房车可经品牌/标题含"宿营/露营"
   车源单独提取，后续可建独立入口与筛选，覆盖宿营车品类。
3. **同款匹配增强**：当前按底盘型号聚合并做别名规范化（欧胜/依维柯欧胜→欧盛），后续可引入车辆名称相似度
   （如"上汽大通V80"与"大通V80"）做更细的跨源同款识别。
4. **定时增量更新**：用系统计划任务每天跑一次 `python crawl.py --pages 2` 与
   `python crawl_21rv.py --pages 5`，增量入库。
5. **打包为APP**：本原型为 Web 应用，后续可用 Capacitor/uni-app 封装为移动端，
   或部署到服务器后做小程序前端。

## 合规提示

- 爬取仅用于个人比价研究，请勿将抓取数据用于商业用途或二次分发。
- 目标网站内容版权归原平台及车商所有；挂牌价仅供参考，以实际沟通为准。
- 请遵守目标网站 robots 协议与服务条款，控制爬取频率。
